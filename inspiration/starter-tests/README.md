# Snippets

In Konsist all checks are tailored for a given project.&#x20;

As the project grows, additional checks can be defined to enforce various rules e.g. layer boundaries, package structure, class naming, and more. The following sections contain a set of sample checks to give an idea of what is achievable with Konsist.

Most snippets are wrapped as [JUnit](https://junit.org/) tests; however, they can easily be wrapped in [Kotest](https://kotest.io/) tests.
